## Vision

### 10x Check
The 10x version makes Playbill Picks feel like a concierge that guides you by the hand from "I want Broadway tickets" to "I'm winning lotteries every day." The wizard doesn't just collect info — it demonstrates the product working in real-time. You connect your account, we verify it live, show you today's open lotteries, and you watch your first entries get submitted.

### Platonic Ideal
The best engineer with perfect taste would build a setup experience where:
- The user never has to read instructions — each step is self-evident
- Connecting rush.telecharge.com feels as safe and natural as "Sign in with Google"
- After setup completes, the dashboard immediately shows "entering you in Hamilton, Wicked, Hadestown..." with live status
- The emotional arc goes: curiosity → trust → excitement → delight
- Zero dead time between "I paid" and "I see value"

## New Flow Architecture

```
Landing → Sign Up (Clerk) → Setup Wizard:
  Step 1: "How Playbill Picks works" (explainer)
  Step 2: "Connect your rush.telecharge.com account"
          [branded form + trust section + verify button]
  Step 3: "Subscribe to automate" → Stripe Checkout
  Step 4: "You're all set!" [completion + next entries]
→ Dashboard (progressive empty state → entries → history)
```

### Key Decisions
- Credentials collected BEFORE payment (trust-building: "we verified your account — now subscribe")
- Dedicated /setup page (clean separation from /dashboard)
- Wizard state tracked via URL params (?step=1..4) for back/forward/refresh support
- Step completion derived from API data (has credentials? has subscription?) not client state

## Error Handling

| Codepath | Failure Mode | User Sees |
|----------|-------------|-----------|
| Cred save | API 500 | "Failed to save. Please try again." + retry |
| Cred verify | Wrong password | "Incorrect email or password." inline |
| Cred verify | Timeout | "Connection timed out. Try again." |
| Cred verify | Rate limited | "Too many attempts. Wait 1 minute." |
| Stripe checkout | Session create fail | "Something went wrong. Please try again." + retry |
| Stripe return | Webhook delayed | Polling with "Activating..." spinner |
